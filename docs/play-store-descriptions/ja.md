# Google Play Store Listing — Japanese (ja-JP)

## Free version (`Reminder`)

### Short description

<!--FREE_SHORT_START-->
```
オフラインで使えるリマインダー・メモ・誕生日管理。データは端末に保存され安心。
```
<!--FREE_SHORT_END-->

### Full description

<!--FREE_FULL_START-->
```
Reminderは、完全オフラインで動作するように作られた、高速でオールインワンのタスク管理アプリです。リマインダーの作成、メモの記録、誕生日の管理をインターネットに接続することなく行えます。すべてのデータは弊社のサーバーではなく、お使いの端末内のプライベートなデータベースに保存されます。

リマインダーとスケジュール
- 一回限り、毎日、毎週、毎月、毎年、そして完全にカスタム可能な繰り返しリマインダー(RRULE対応)
- 特定の場所への到着・出発をきっかけに発動する位置情報リマインダー
- リマインダーのアクション:電話をかける、SMSやメールを送信する、リンクを開く、アプリを起動する、買い物リストを進める
- グループ、優先度レベル、色分けタグで整理
- サブタスク付きの買い物リストリマインダー
- 自分の好きな時間帯に通知を止められるサイレントタイム(おやすみモード)
- 「今日」「期限切れ」「今週」などをその場で計算するスマートリスト
- 発動したすべてのリマインダーの完全な履歴
- お気に入りの繰り返しパターンを保存し、ワンタップで再利用

メモ
- リッチテキスト書式と写真添付に対応したクイックメモ
- 書いた内容をすべて検索・フィルタリング
- メモを標準的なiCalendar形式でエクスポート

誕生日
- 電話のカレンダーとは別に誕生日を管理
- 今日または近日中に誕生日を迎える人をひと目で確認

カレンダー
- リマインダー、誕生日、Google Tasksの期限を一つにまとめたカレンダー表示

Google タスク(任意・要ログイン)
- Google タスクのリストを完全な双方向同期で閲覧・管理

ウィジェットとクイックアクセス
- リマインダー、メモ、誕生日、タスク用のホーム画面ウィジェット
- クイック設定からワンタップで「リマインダーを追加」できるタイル

自分好みにカスタマイズ
- 好みのカラースキームを選べるMaterial 3デザイン
- 通知音とバイブレーションパターンのカスタマイズ
- データをiCalendar(.ics)形式でインポート・エクスポート
- 指紋または顔認証でアプリをロック

設計思想としてのプライバシー
Reminderはオフラインファーストの考え方で作られています。リマインダー、メモ、誕生日、グループ、場所情報はすべて端末内のローカルデータベースに保存され、ご自身で要求しない限りどこにもアップロードされません。複数端末で同期したいときはいつでもGoogle DriveまたはDropboxのバックアップを有効にできます - データはご自身のクラウドアカウント内のプライベートフォルダに直接送られ、弊社が運営するサーバーに送られることは一切ありません。位置情報、連絡先、カメラ、マイク、生体認証の権限はすべて任意であり、それぞれの機能のためだけに使用されます。

この無料版は広告によって運営されています。広告なしで端末内のストリーク統計、暗号化されたローカルバックップ、Gemini AppFunctions連携を利用したい場合は、Reminder PROをぜひご確認ください。
```
<!--FREE_FULL_END-->
