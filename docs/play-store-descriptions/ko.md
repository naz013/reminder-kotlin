### Full description

<!--FREE_FULL_START-->
```
Reminder는 완전한 오프라인 작동을 위해 만들어진 빠르고 올인원인 작업 관리 앱입니다. 인터넷에 연결하지 않고도 리마인더를 만들고, 메모를 작성하고, 생일을 관리할 수 있습니다 - 모든 데이터는 저희 서버가 아닌 기기 내 개인 데이터베이스에 저장됩니다.

리마인더 및 일정 관리
- 일회성, 매일, 매주, 매월, 매년 및 완전히 사용자 지정 가능한 반복 리마인더(RRULE 지원)
- 특정 장소에 도착하거나 떠날 때 실행되는 위치 기반 리마인더
- 리마인더 액션: 전화 걸기, SMS 또는 이메일 보내기, 링크 열기, 앱 실행하기, 쇼핑 목록 처리하기
- 그룹, 우선순위 수준, 색상 태그로 정리
- 하위 작업이 있는 쇼핑 목록 리마인더
- 원하는 시간대에 알림을 끌 수 있는 방해 금지 모드
- 오늘, 기한 초과, 이번 주 등을 기기에서 즉시 계산하는 스마트 목록
- 실행된 모든 리마인더의 전체 기록
- 즐겨 찾는 반복 패턴을 저장하고 한 번의 탭으로 재사용

메모
- 서식 있는 텍스트와 사진 첨부가 가능한 빠른 메모
- 작성한 모든 내용을 검색하고 필터링
- 메모를 표준 iCalendar 파일로 내보내기

생일
- 휴대폰 캘린더와 별개로 생일 관리
- 오늘 또는 곧 생일을 맞이하는 사람을 한눈에 확인

캘린더
- 리마인더, 생일, Google Tasks 마감일을 하나로 모은 통합 캘린더 보기

Google Tasks(선택 사항, 로그인 필요)
- 완전한 양방향 동기화로 Google Tasks 목록을 탐색하고 관리

위젯 및 빠른 액세스
- 리마인더, 메모, 생일, 작업을 위한 홈 화면 위젯
- 빠른 설정에서 원터치로 "리마인더 추가"

내 취향대로 설정
- 원하는 색상 구성으로 Material 3 디자인
- 맞춤 알림음 및 진동 패턴
- 데이터를 iCalendar(.ics) 파일로 가져오기 및 내보내기
- 지문 또는 얼굴 인식으로 앱 잠금

설계 단계부터의 프라이버시
Reminder는 오프라인 우선 설계로 만들어졌습니다. 리마인더, 메모, 생일, 그룹, 장소는 모두 기기 내 로컬 데이터베이스에 저장되며, 직접 요청하지 않는 한 어디에도 업로드되지 않습니다. 언제든지 Google Drive 또는 Dropbox 백업을 켜서 기기 간 동기화를 할 수 있습니다 - 데이터는 저희가 운영하는 서버가 아닌, 사용자 본인의 클라우드 계정 내 개인 폴더로 바로 전송됩니다. 위치, 연락처, 카메라, 마이크, 생체 인식 권한은 모두 선택 사항이며 해당 기능에만 사용됩니다.

이 무료 버전은 광고로 운영됩니다. 광고 없이 기기 내 스트릭 인사이트, 암호화된 로컬 백업, Gemini AppFunctions 연동을 원하신다면 Reminder PRO를 확인해 보세요.
```
