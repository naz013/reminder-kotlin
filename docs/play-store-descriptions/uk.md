## Free version (`Reminder`)

### Short description

<!--FREE_SHORT_START-->
```
Офлайн-нагадування, нотатки й дні народження. Приватно, дані на пристрої.
```
<!--FREE_SHORT_END-->

### Full description

<!--FREE_FULL_START-->
```
Reminder - швидкий універсальний планувальник задач, створений для повністю офлайн-роботи. Створюйте нагадування, робіть нотатки та відстежуйте дні народження, жодного разу не виходячи в мережу - усе зберігається в приватній базі даних на вашому пристрої, а не на наших серверах.

НАГАДУВАННЯ ТА ПЛАНУВАННЯ
- Одноразові, щоденні, щотижневі, щомісячні, щорічні та повністю налаштовувані повторювані нагадування (підтримка RRULE)
- Нагадування за геолокацією, що спрацьовують при прибутті на місце або виході з нього
- Дії нагадування: подзвонити, надіслати SMS чи листа, відкрити посилання, запустити застосунок або пройтися списком покупок
- Організовуйте за допомогою груп, рівнів пріоритету та кольорових міток
- Нагадування-списки покупок із підзадачами
- Тихі години (Не турбувати) для вимкнення сповіщень за власним розкладом
- Розумні списки - Сьогодні, Прострочені, Цього тижня та інші - розраховуються миттєво на вашому пристрої
- Повна історія кожного спрацьованого нагадування
- Зберігайте улюблені шаблони повторення та застосовуйте їх одним дотиком

НОТАТКИ
- Швидкі нотатки з форматуванням тексту та вкладенням фото
- Пошук і фільтрування за всім написаним
- Експорт нотаток у стандартному форматі iCalendar

ДНІ НАРОДЖЕННЯ
- Відстежуйте дні народження незалежно від календаря телефону
- Дивіться, у кого день народження сьогодні або незабаром

КАЛЕНДАР
- Єдиний календар із нагадуваннями, днями народження та термінами з Google Tasks

GOOGLE TASKS (за бажанням, потрібен вхід)
- Переглядайте та керуйте списками Google Tasks з повною двосторонньою синхронізацією

ВІДЖЕТИ ТА ШВИДКИЙ ДОСТУП
- Віджети на головному екрані для нагадувань, нотаток, днів народження та завдань
- Плитка швидких налаштувань "Додати нагадування" в один дотик

НАЛАШТУЙТЕ ПІД СЕБЕ
- Дизайн Material 3 з вибором кольорової схеми
- Власні звуки сповіщень і шаблони вібрації
- Імпорт та експорт даних у форматі iCalendar (.ics)
- Блокування застосунку за відбитком пальця або обличчям

ПРИВАТНІСТЬ ЗА ЗАДУМОМ
Reminder спочатку створювався офлайн-орієнтованим. Ваші нагадування, нотатки, дні народження, групи та місця зберігаються в локальній базі даних на пристрої й нікуди не завантажуються, якщо ви самі цього не попросите. Будь-коли вмикайте резервне копіювання в Google Drive або Dropbox для синхронізації між пристроями - дані потрапляють прямо в приватну папку вашого власного хмарного акаунта, а не на керований нами сервер. Дозволи на геолокацію, контакти, камеру, мікрофон і біометрію завжди необов'язкові й використовуються лише для конкретної функції, яку вони забезпечують.

Ця безкоштовна версія існує завдяки рекламі. Щоб працювати без реклами, з локальною статистикою серій, зашифрованими локальними резервними копіями та інтеграцією Gemini AppFunctions, спробуйте Reminder PRO.
```
