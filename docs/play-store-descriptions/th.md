## Free version (`Reminder`)

### Short description

```
เตือนความจำ โน้ต และวันเกิดแบบออฟไลน์ เป็นส่วนตัว ข้อมูลอยู่ในเครื่องคุณเท่านั้น
```

### Full description

<!--FREE_FULL_START-->
```
Reminder คือแอปจัดการงานแบบครบวงจรที่รวดเร็ว ออกแบบมาให้ทำงานแบบออฟไลน์ทั้งหมด สร้างการเตือนความจำ จดโน้ต และติดตามวันเกิดโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ตเลย - ข้อมูลทั้งหมดถูกเก็บไว้ในฐานข้อมูลส่วนตัวบนอุปกรณ์ของคุณ ไม่ใช่บนเซิร์ฟเวอร์ของเรา

การเตือนความจำและการจัดตารางเวลา
- การเตือนแบบครั้งเดียว รายวัน รายสัปดาห์ รายเดือน รายปี และแบบทำซ้ำที่กำหนดเองได้อย่างเต็มที่ (รองรับ RRULE)
- การเตือนตามตำแหน่งที่ตั้ง ซึ่งทำงานเมื่อคุณไปถึงหรือออกจากสถานที่
- การกระทำของการเตือน: โทรออก ส่ง SMS หรืออีเมล เปิดลิงก์ เปิดแอป หรือทำรายการซื้อของให้เสร็จ
- จัดระเบียบด้วยกลุ่ม ระดับความสำคัญ และแท็กสี
- การเตือนแบบรายการซื้อของพร้อมงานย่อย
- ช่วงเวลาเงียบ (ห้ามรบกวน) เพื่อปิดเสียงการแจ้งเตือนตามตารางเวลาของคุณเอง
- รายการอัจฉริยะ - วันนี้ เลยกำหนด สัปดาห์นี้ และอื่น ๆ - คำนวณทันทีบนอุปกรณ์ของคุณ
- ประวัติที่สมบูรณ์ของการเตือนความจำทุกครั้งที่ทำงาน
- บันทึกรูปแบบการทำซ้ำที่คุณชื่นชอบและนำมาใช้ใหม่ได้ในแตะเดียว

โน้ต
- โน้ตด่วนพร้อมการจัดรูปแบบข้อความและแนบรูปภาพ
- ค้นหาและกรองทุกสิ่งที่คุณเคยเขียน
- ส่งออกโน้ตเป็นไฟล์ iCalendar มาตรฐาน

วันเกิด
- ติดตามวันเกิดแยกจากปฏิทินโทรศัพท์ของคุณ
- ดูว่าใครมีวันเกิดวันนี้หรือเร็ว ๆ นี้

ปฏิทิน
- มุมมองปฏิทินรวมเดียวสำหรับการเตือนความจำ วันเกิด และกำหนดส่งของ Google Tasks

Google Tasks (ไม่บังคับ ต้องเข้าสู่ระบบ)
- เรียกดูและจัดการรายการ Google Tasks ของคุณด้วยการซิงค์สองทางแบบเต็มรูปแบบ

วิดเจ็ตและการเข้าถึงด่วน
- วิดเจ็ตหน้าจอหลักสำหรับการเตือนความจำ โน้ต วันเกิด และงาน
- ปุ่มลัด "เพิ่มการเตือนความจำ" ในการตั้งค่าด่วน แตะเดียวจบ

ปรับแต่งให้เป็นสไตล์ของคุณ
- ดีไซน์ Material 3 พร้อมโทนสีที่คุณเลือกเอง
- เสียงแจ้งเตือนและรูปแบบการสั่นแบบกำหนดเอง
- นำเข้าและส่งออกข้อมูลของคุณเป็นไฟล์ iCalendar (.ics)
- ล็อกแอปด้วยลายนิ้วมือหรือใบหน้า

เป็นส่วนตัวตั้งแต่การออกแบบ
Reminder ถูกออกแบบโดยยึดออฟไลน์เป็นหลัก การเตือนความจำ โน้ต วันเกิด กลุ่ม และสถานที่ของคุณอยู่ในฐานข้อมูลภายในเครื่องบนอุปกรณ์ของคุณ และจะไม่ถูกอัปโหลดไปที่ใดเลยเว้นแต่คุณจะร้องขอเอง เปิดใช้การสำรองข้อมูล Google Drive หรือ Dropbox เมื่อใดก็ได้เพื่อซิงค์ข้ามอุปกรณ์ - ข้อมูลของคุณจะไปยังโฟลเดอร์ส่วนตัวในบัญชีคลาวด์ของคุณเองโดยตรง ไม่ใช่ไปยังเซิร์ฟเวอร์ที่เราดำเนินการ สิทธิ์การเข้าถึงตำแหน่งที่ตั้ง รายชื่อติดต่อ กล้อง ไมโครโฟน และไบโอเมตริกซ์เป็นทางเลือกเสมอ และใช้เฉพาะสำหรับฟีเจอร์เฉพาะที่สิทธิ์นั้นรองรับเท่านั้น

แอปฟรีเวอร์ชันนี้ได้รับการสนับสนุนจากโฆษณา สำหรับประสบการณ์ที่ไม่มีโฆษณา พร้อมสถิติสตรีคบนอุปกรณ์ การสำรองข้อมูลภายในเครื่องแบบเข้ารหัส และการเชื่อมต่อ Gemini AppFunctions ลองดู Reminder PRO
```

```
สตรีคและสถิติ (PRO)
- ดูสตรีคการเตือนความจำ แนวโน้มกิจกรรมรายสัปดาห์ และวันที่ยุ่งที่สุดได้ในมองแวบเดียว
```
