## Free version (`Reminder`)

### Short description

```

```

### Full description

<!--FREE_FULL_START-->
```
Reminder 是一款快速、全能的任务管理应用,专为完全离线使用而设计。无需联网即可创建提醒、记笔记、追踪生日 - 所有数据都保存在设备上的私密数据库中,而不是我们的服务器上。

提醒与日程安排
- 支持一次性、每日、每周、每月、每年以及完全自定义的重复提醒(支持 RRULE)
- 基于位置的提醒,可在到达或离开某个地点时触发
- 提醒操作:拨打电话、发送短信或邮件、打开链接、启动应用,或完成购物清单
- 使用分组、优先级和彩色标签进行整理
- 带子任务的购物清单提醒
- 免打扰时段,按照你自己的时间表静音通知
- 智能列表 - 今天、已逾期、本周等 - 在设备上即时计算
- 每条已触发提醒的完整历史记录
- 保存你喜欢的重复模式,一键复用

笔记
- 支持富文本格式和图片附件的快速笔记
- 搜索并筛选你写下的所有内容
- 将笔记导出为标准的 iCalendar 文件

生日
- 独立于手机日历追踪生日
- 一眼看清今天或近期谁过生日

日历
- 将提醒、生日和 Google 任务的截止日期整合在一个日历视图中

Google 任务(可选,需要登录)
- 浏览并管理你的 Google 任务列表,支持完整双向同步

小组件与快速访问
- 用于提醒、笔记、生日和任务的主屏幕小组件
- 快速设置中的"添加提醒"磁贴,一键直达

打造属于你的样式
- Material 3 设计,可自选配色方案
- 自定义通知铃声和振动模式
- 以 iCalendar(.ics)格式导入和导出数据
- 使用指纹或人脸识别锁定应用

设计之初就重视隐私
Reminder 始终以离线优先为设计理念。你的提醒、笔记、生日、分组和地点都保存在设备本地数据库中,除非你主动要求,否则绝不会上传到任何地方。你可以随时开启 Google 云端硬盘或 Dropbox 备份以实现跨设备同步 - 数据会直接进入你自己云账户中的私密文件夹,绝不会进入我们运营的服务器。位置、通讯录、相机、麦克风和生物识别权限均为可选,且只用于其对应的具体功能。

此免费版本由广告支持。如果想获得无广告体验,并使用设备端连续记录统计、加密本地备份及 Gemini AppFunctions 集成,欢迎了解 Reminder PRO。
```
