How to Create and Customize Reminders

A comprehensive guide to using the reminder builder

Getting Started

The reminder builder is a powerful, modular system that allows you to create customized reminders by combining different building blocks. Each reminder is constructed by adding and configuring various components to match your specific needs.

Key Concept

Think of creating a reminder like building with LEGO blocks. Each block (Builder Item) has a specific function, and you combine them to create the exact reminder you need.

Basic Workflow

1

Open the Reminder Builder

Navigate to the reminder creation screen. You'll see an empty builder with a floating action button (FAB) in the bottom-right corner.

2

Add Builder Items

Tap the add button (FAB) to open the selector dialog. This dialog has three tabs:

  • Builder Items - Individual components to build your reminder
  • Presets - Pre-configured templates for common reminder types
  • Recur Presets - Advanced recurring patterns (Pro feature)
3

Configure Each Item

After adding an item, tap on it to configure its specific settings. Each item type has its own configuration dialog.

4

Review the Prediction

As you build, the system shows a forecast of when your reminder will trigger. This helps you verify that the configuration is correct.

5

Save Your Reminder

Once all items are configured correctly, tap the save icon in the top menu. The system will validate your configuration and activate the reminder.

Builder Item Categories

Core Items CORE

These are the fundamental building blocks that define when your reminder will trigger:

Date

Set a specific date for your reminder. Must be combined with Time. Cannot be used with recurring reminders or location-based reminders.

Time

Set a specific time of day. Required when using Date. Works independently with Days of Week.

Days of Week

Select specific weekdays (e.g., Monday, Wednesday, Friday) for recurring reminders. Perfect for alarms and weekly events.

Day of Month

Repeat on a specific day each month (e.g., 15th of every month). Great for monthly bills or meetings.

Day of Year

Trigger once per year on a specific date (e.g., birthdays, anniversaries).

Countdown Timer

Set a timer that counts down from now (e.g., in 2 hours, in 30 minutes). Perfect for quick reminders.

Arriving at Location

Trigger when you arrive at a specific place. Requires location permissions.

Leaving Location

Trigger when you leave a specific place. Requires location permissions.

Constraint Rules

Core items have mutual exclusivity rules. For example, you cannot combine Date with Days of Week, or use location-based triggers with countdown timers. The system will automatically disable incompatible options.

Parameter Items PARAMS

These items modify the behavior of your reminder:

Summary

The main text/title of your reminder. This is what you'll see in the notification.

Group

Assign the reminder to a category or group for better organization.

Before Time

Show a notification X minutes/hours before the main event (e.g., 15 minutes before a meeting).

Repeat Time

How often to repeat the notification (e.g., every 2 hours, every day). Works with Date, Time, or Countdown Timer.

Repeat Interval

Advanced: Set precise intervals between repetitions (milliseconds).

Repeat Limit

Stop repeating after X occurrences. Prevents infinite repetitions.

Location Delay Date/Time

For location-based reminders, wait until a specific date/time after arriving/leaving before triggering.

Timer Exclusion

Set time ranges when countdown timers should NOT trigger (e.g., don't remind me during sleep hours).

Action Items ACTION

Define what action the reminder should perform when triggered:

Phone Call

Automatically initiate a phone call to a specific number.

SMS

Send a text message to a specific number.

Email

Open email composer with pre-filled recipient and optional subject.

Open Link

Open a specific URL in the browser when the reminder triggers.

Launch Application

Open a specific app on your device (Android 12 and below).

Sub-tasks (Shopping List)

Create a checklist of items within the reminder. Perfect for shopping lists or todo items.

Note About Actions

You can only use ONE action type per reminder. For example, you cannot combine Phone Call with SMS. However, you can attach a Note to any reminder type for additional information.

Extra Items EXTRA

Additional customization options:

Description

Add detailed notes or additional information to your reminder.

Note Attachment

Link an existing note from your notes collection to the reminder.

Priority

Set notification priority (Default, High, Low, etc.) to control how prominently it's displayed.

LED Color

Choose the LED notification light color (for devices that support it).

Melody

Select a custom ringtone or sound for the notification.

Vibration

Configure vibration pattern for the notification.

Do Not Disturb Override

Allow the reminder to bypass Do Not Disturb mode.

Common Use Cases

1. Simple One-Time Reminder

Goal: Remind me to call mom tomorrow at 3 PM

  • Add Summary: "Call mom"
  • Add Date: Tomorrow's date
  • Add Time: 3:00 PM

2. Recurring Alarm

Goal: Wake me up at 7 AM on weekdays

  • Add Summary: "Wake up!"
  • Add Days of Week: Monday - Friday
  • Add Time: 7:00 AM
  • Optional: Add Melody for alarm sound

3. Location-Based Reminder

Goal: Remind me to buy milk when I arrive at the grocery store

  • Add Summary: "Buy milk"
  • Add Arriving at Location: Select or search for grocery store
  • Set radius (e.g., 150 meters)

Permissions Required: Location access, Background location (Android 10+)

4. Countdown Timer with Action

Goal: Call the dentist in 2 hours

  • Add Summary: "Call dentist"
  • Add Countdown Timer: 2 hours
  • Add Phone Call: Enter dentist's phone number

5. Monthly Bill Reminder

Goal: Pay rent on the 1st of every month at 9 AM

  • Add Summary: "Pay rent"
  • Add Day of Month: 1st
  • Add Time: 9:00 AM
  • Optional: Add Before Time: 1 day (to get advance notice)

6. Shopping List

Goal: Remember to buy multiple items at the store

  • Add Summary: "Grocery shopping"
  • Add Sub-tasks: Bread, Milk, Eggs, etc.
  • Add Date and Time OR Arriving at Location

7. Birthday Reminder

Goal: Remember friend's birthday every year

  • Add Summary: "Sarah's Birthday"
  • Add Day of Year: Select the date
  • Add Time: 9:00 AM
  • Optional: Add Before Time: 1 week (to give time to prepare)

Using Presets

Presets are pre-configured templates that automatically add the right combination of builder items for common scenarios. This saves time and ensures compatibility.

Available Preset Categories

Default Presets (Available to All Users)

  • By Date - Single event at specific date and time
  • Timer - Countdown from now
  • Alarm - Recurring weekday alarm
  • Email - Reminder to send an email
  • Application - Launch specific app
  • Monthly - Monthly recurring reminder
  • Yearly - Annual reminder
  • Shopping List - Permanent shopping checklist
  • Call - Phone call reminder
  • Link - Open URL reminder
  • Arriving at Place - Location-based trigger
  • Leaving Place - Location departure trigger

Builder Presets PRO

  • Exact Date and Time - Basic one-time reminder
  • Date and Time with Repeat - Custom repetition interval
  • Weekday Alarm - Monday to Friday alarm
  • Make Call in 3 Hours - Quick phone call timer
  • Open Link at Location - Combined location + web action
  • Permanent Shopping List - Pre-populated shopping items

Recur Presets PRO

Advanced iCalendar-based recurring patterns for complex scheduling needs. These use the iCalendar RRULE standard for maximum flexibility.

Tip: Modify Presets

After applying a preset, you can add, remove, or modify any builder items to customize it further. Presets are just starting points!

Item States and Validation

Each builder item can have one of three states:

StateMeaning
EmptyThe item has been added but not configured yet. You need to tap it and set values.
DoneThe item is properly configured and valid.
ErrorThe item has invalid or conflicting values. Check the error message and fix it.

Save Conditions

You can only save a reminder when:

  • All items are in Done state (green checkmark)
  • No permission requirements are missing
  • The forecast shows a valid trigger time
  • All constraint rules are satisfied

Permissions

Certain builder items require specific Android permissions:

Builder ItemRequired Permissions
Phone CallPhone
SMSSMS, Contacts
Arriving/Leaving LocationFine Location, Coarse Location, Background Location (Android 10+), Foreground Service
All Reminders (Android 13+)Post Notifications

The app will automatically request these permissions when you add items that require them. If you deny permissions, those items will show an error state.

Advanced Configuration

Reminder Forecast

As you configure your reminder, the forecast section shows when the next notification will appear. This helps you verify your setup is correct before saving.

  • Success Prediction: Shows next trigger time(s)
  • Failed Prediction: Indicates configuration errors with helpful messages

Save as Preset

If you create a reminder configuration you want to reuse later, enable the "Save as Preset" option at the bottom of the screen. Give it a memorable name, and it will appear in your Presets tab for quick access in the future.

Builder Configuration

Access the configuration menu to customize which builder items are available. You can disable items you never use to simplify the selector dialog.

Menu Actions

Save

Saves and activates the reminder. Only enabled when the configuration is valid.

Delete / Archive

For existing reminders, you can either move to archive (soft delete) or permanently delete. Archived reminders can be restored later.

Configure

Opens settings to customize which builder items are shown in the selector.

Report Issue

Opens feedback form to report bugs or suggest improvements. Can optionally attach logs (Pro feature).

Best Practices

Do This

  • Start with a preset when available - it's faster and ensures compatibility
  • Check the forecast before saving to verify trigger time
  • Use descriptive Summary text - you'll see it in notifications
  • Group related reminders using the Group item
  • Set Repeat Limit to prevent infinite notifications
  • Use Before Time for important events to get advance notice

Avoid This

  • Don't mix incompatible core items (e.g., Date + Days of Week)
  • Don't forget to configure items after adding them
  • Don't add multiple action types to one reminder
  • Don't set countdown timers for past times
  • Don't ignore permission requests - they're required for functionality

Troubleshooting

Can't save the reminder

Solution: Check that all items show green checkmarks. Look for error badges and tap items to fix configuration.

Forecast shows error

Solution: You have conflicting builder items. Remove incompatible items or choose an alternative configuration.

Builder item is grayed out

Solution: That item is incompatible with your current configuration, requires Pro version, or needs missing permissions.

Location reminder not working

Solution: Ensure all location permissions are granted, including Background Location. Check that radius is appropriate (too small may miss triggers).

Preset not loading

Solution: Some presets require Pro version or specific permissions. Grant permissions or upgrade to Pro.

Summary

The reminder builder is a flexible, modular system that lets you create exactly the reminder you need. Start with the core timing item (Date, Timer, Location, etc.), add parameters to refine behavior, optionally add an action, and customize with extra items. The system guides you with constraints, validation, and forecasts to ensure your reminder works as expected.

Pro Tip

Experiment with different combinations! The builder is designed to prevent invalid configurations, so feel free to try different items and see what works. Use presets as learning tools to understand how different items work together.
